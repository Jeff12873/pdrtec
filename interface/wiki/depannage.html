Questions fréquentes et astuces

« Connexion à la GMAO indisponible »

Sans connexion, glissez sur la page un export Excel du rapport de recherche de pièces : il est lu dans le navigateur et n'est envoyé nulle part.

Les photos ne s'affichent pas

Elles ne s'affichent que depuis le réseau de l'entreprise. Admin Vérifiez le modèle de lien dans les Paramètres.

Une famille en jaune est fausse

C'est une proposition : elle n'est jamais écrite dans la GMAO. Classez la pièce dans la GMAO, la proposition disparaît.

Trucs et astuces

  • Les accents et les majuscules sont ignorés : tapez vite, sans vous soucier de l'orthographe exacte.
  • Copiez le code d'un clic (icône à droite du code) pour le coller dans la GMAO.
