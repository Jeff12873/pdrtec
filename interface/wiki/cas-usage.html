Cas d'usage

1. Retrouver la pièce d'une plaque signalétique

  1. Tapez la référence lue sur la plaque, ou ses premiers caractères.
  2. Rien ? Tapez ce qu'est la pièce (« vérin », « capteur ») et filtrez par caractéristique (course, diamètre, tension).
  3. Ouvrez la ligne : l'emplacement au magasin et les machines où elle est déjà montée.

2. Trouver un remplaçant compatible

  1. Ouvrez la pièce d'origine et notez ses caractéristiques.
  2. Choisissez la même famille et sous-famille, puis réglez les filtres sur ces caractéristiques.
  3. Comparez les pièces restantes dans le tableau, colonne par colonne.

3. Vérifier ce qui est monté sur une machine

  1. Tapez le code de la machine dans la recherche.
  2. Les pièces dont l'observation ou les machines citent ce code apparaissent.

4. Classer les pièces sans famille

  1. Laissez la case « familles proposées » cochée.
  2. Repérez les propositions en jaune, survolez pour voir pourquoi.
  3. Reportez dans la GMAO celles qui sont justes : elles servent ensuite à mieux proposer les autres.
