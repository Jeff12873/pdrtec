Rechercher une pièce

Retrouver une pièce de rechange par son code, sa désignation, ses caractéristiques ou son emplacement, directement dans la base de la GMAO.

Pas à pas

  1. Tapez un ou plusieurs mots dans la barre : code, désignation, référence fabricant, observation.
  2. Affinez avec la famille puis la sous-famille.
  3. Utilisez les filtres des caractéristiques qui apparaissent (diamètre, filetage, tension…).
  4. Cliquez sur une ligne : photo, emplacement, machines, pièces jointes. L'icône à côté du code le copie.

Les familles proposées (en jaune)

Une pièce sans famille dans la GMAO reçoit une proposition, en jaune, apprise sur les pièces déjà classées. Survolez-la pour voir pourquoi. Elle n'est jamais écrite dans la GMAO : reportez-la si elle est juste.

Questions fréquentes

Une chèvre remplace les photos

Les photos ne s'affichent que depuis le réseau de l'entreprise.

Sinon, le serveur des photos ou le modèle de lien n'est pas réglé : voir Paramètres.

Je ne trouve pas une pièce que je connais

Essayez un seul mot, sans accent ni pluriel, ou le début du code. Retirez les filtres de famille : la pièce n'est peut-être pas classée.

Les données ne sont pas à jour

Actualiser depuis la base relit la GMAO.

Trucs et astuces

  • Mettez une expression entre guillemets pour la chercher telle quelle : "REP 19".
  • Pour une pièce électrique, tapez la tension dans le champ dédié : PDRTEC garde les pièces dont la plage la couvre.
  • Une pièce réversible (flexible…) est trouvée dans un sens comme dans l'autre.
